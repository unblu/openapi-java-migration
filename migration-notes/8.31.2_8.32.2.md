# 8.31.2 → 8.32.2

One message type was removed.

**This release breaks java code.** See [Required migration](#required-migration).

## What changed
The enum constant `EMessageType.WHATSAPP_TEMPLATE` was removed. Thirteen message types
remain.

## Required migration

Remove the branch. Any code comparing against the constant no longer compiles.

```java
// before
if (message.getType() == EMessageType.WHATSAPP_TEMPLATE) { ... }
```
