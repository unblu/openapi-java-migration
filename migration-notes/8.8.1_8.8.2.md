# 8.8.1 → 8.8.2

The deputy escalation level enum was replaced.

**This release breaks java code.** See [Required migration](#required-migration).

## What changed
`EDeputyDelegationEscalationLevel` was replaced by
`EAssistantAndDeputyDelegationEscalationLevel` everywhere it appeared: on
`DeputyRelationship` and on the four escalation-level operators
(`Equals`, `NotEquals`, `In`, `NotIn`).

The constants themselves are unchanged; only the type is different.

## Required migration

Change the type; the values stay the same.

```java
// before
relationship.setEscalationLevel(EDeputyDelegationEscalationLevel.LEVEL_1);

// after
relationship.setEscalationLevel(EAssistantAndDeputyDelegationEscalationLevel.LEVEL_1);
```

The same applies to the `value(..)` and `values(..)` setters of the operators, and to
the return type of their getters.
