# 8.37.2 → 8.38.2

Two WhatsApp template enums were renamed to fix a spelling mistake.

**This release breaks java code.** See [Required migration](#required-migration).

## What changed
`ETemplateComponentParemetersType` and `ETemplateComponentParemetersSubType` — note
"Paremeters" — were removed and replaced by `ETemplateComponentParametersType` and
`ETemplateComponentParametersSubType`.

This changes the signatures of `WhatsAppTemplateComponentParameters.setType(..)`,
`setSubType(..)`, their fluent equivalents and their getters.

## Required migration

Correct the spelling in the type names. The constants are unchanged.

```java
// before
parameters.setType(ETemplateComponentParemetersType.BUTTON);
parameters.setSubType(ETemplateComponentParemetersSubType.QUICK_REPLY);

// after
parameters.setType(ETemplateComponentParametersType.BUTTON);
parameters.setSubType(ETemplateComponentParametersSubType.QUICK_REPLY);
```

Take care not to confuse the renamed `ETemplateComponentParametersType` with the
*singular* `ETemplateComponentParameterType` introduced in the same release: they are
different types.
