# 8.3.1 → 8.4.2

One offboarding reason was removed.

**This release breaks java code.** See [Required migration](#required-migration).

## What changed
The enum constant `EOffboardingReason.EXTERNAL_CHANNEL_CLOSED` was removed.

The value only ever reaches a client inside a webhook payload, so this affects code that
branches on the reason a participant was offboarded.

## Required migration

Remove the branch. Any code that compares against the constant no longer compiles.

```java
// before
if (reason == EOffboardingReason.EXTERNAL_CHANNEL_CLOSED) { ... }
```

There is no replacement constant: the situation is now reported under one of the
remaining reasons.
