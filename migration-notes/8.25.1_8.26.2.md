# 8.25.1 → 8.26.2

The "try a summary template" operation was removed.

**This release breaks java code.** See [Required migration](#required-migration).

## What changed
* `ConversationSummaryTemplatesApi.conversationSummaryTemplatesGenerateSummaryTryForTemplate(..)`
  was removed, along with its `WithHttpInfo` variant
* its request body class `ConversationSummaryTemplateTest` was removed
* the enum constant `ESummarizationTimeFrame.WHOLE_CONVERSATION_WITHOUT_ONBOARDING` was
  removed

## Required migration

There is no replacement for the operation: remove the calls.

For the time frame, choose another value — `WHOLE_CONVERSATION`, `UNTIL_LAST_SUMMARY`,
`UNTIL_LAST_UNASSIGNED` or `TRIGGER_SPECIFIC`:

```java
// before
template.setSummarizationTimeFrame(ESummarizationTimeFrame.WHOLE_CONVERSATION_WITHOUT_ONBOARDING);

// after
template.setSummarizationTimeFrame(ESummarizationTimeFrame.WHOLE_CONVERSATION);
```

The REST endpoint was removed too, and the server no longer accepts the removed time
frame, so an un-migrated client receives `404` and `400` respectively.
