# 8.14.4 → 8.15.3

`DialogBotData` became an interface.

**This release breaks java code.** See [Required migration](#required-migration).

## What changed
`DialogBotData` is now an interface, implemented by `CustomDialogBotData` and
`CopilotDialogBotData`. Its `TypeEnum` was removed, its methods became abstract, and its
`JSON_PROPERTY_*` constants disappeared.

Same shape as the `SuggestionSourceData` change one release earlier: the model gained
its first variants, so the generated type became an interface.

## Required migration

`new DialogBotData()` no longer compiles. The pre-8.15.3 class corresponds to
`CustomDialogBotData`.

```java
// before
DialogBotData bot = new DialogBotData();
bot.set$Type(DialogBotData.TypeEnum.DIALOGBOTDATA);

// after
CustomDialogBotData bot = new CustomDialogBotData();
bot.set$Type(CustomDialogBotData.TypeEnum.CUSTOMDIALOGBOTDATA);
```

The variant also has `getType()` / `setType(EBotType)`, which the old class did not.
