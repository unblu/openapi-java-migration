# 8.17.1 → 8.18.0

The auxiliary camera type enum was renamed.

**This release breaks java code.** See [Required migration](#required-migration).

## What changed
`EBranchClientAuxiliaryCameraType` was removed and replaced by `EAuxiliaryCameraType`.
The constants are unchanged: `DOCUMENT`, `ROOM`, `OTHER`.

This changes the signatures of `BranchClientAuxiliaryCameraData.setType(..)`,
`type(..)` and `getType()`.

## Required migration

Change the type name; the values stay the same.

```java
// before
camera.setType(EBranchClientAuxiliaryCameraType.DOCUMENT);

// after
camera.setType(EAuxiliaryCameraType.DOCUMENT);
```
