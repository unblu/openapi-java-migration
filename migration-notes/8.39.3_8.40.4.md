# 8.39.3 → 8.40.4

The "person label" vocabulary was renamed to "label".

**This release breaks java code.** See [Required migration](#required-migration).

## What changed
Every `PersonLabel*` type was renamed to `Label*`:

| before | after |
|---|---|
| `PersonLabel` | `Label` |
| `PersonLabelList` | `LabelList` |
| `PersonLabelQuery` | `LabelQuery` |
| `PersonLabelResult` | `LabelResult` |
| `PersonLabelOrderBy` | `LabelOrderBy` |
| `PersonLabelSearchFilter` | `LabelSearchFilter` |
| `PersonLabelsOperator` | `LabelsOperator` |
| `PersonLabelModificationEvent` | `LabelModificationEvent` |
| `NamePersonLabelSearchFilter` | `NameLabelSearchFilter` |
| `AllOfPersonLabelsOperator` | `AllOfLabelsOperator` |
| `AnyOfPersonLabelsOperator` | `AnyOfLabelsOperator` |
| `NoneOfPersonLabelsOperator` | `NoneOfLabelsOperator` |
| `EPersonLabelTargetType` | `ELabelTargetType` |
| `EPersonLabelManagementRole` | `ELabelManagementRole` |
| `EPersonLabelOrderByField` | `ELabelOrderByField` |
| `EPersonLabelSearchFilterField` | `ELabelSearchFilterField` |
| `EPersonLabelsOperatorType` | `ELabelsOperatorType` |

Everything that mentions one of them changes with it: every `PersonLabelsApi` operation,
`PersonData.getLabels()`, `ContextPersonInfo.getLabels()`, and the label filters on the
person queries. `PersonLabelsApi` itself keeps its name, and its operations are now
marked deprecated.

Unrelated to the rename, `LicenseData.putFeaturesItem(String, Object)` now takes a
`JsonNode` value.

The wire format did not change: the discriminator values `NAME`, `ALL_OF`, `ANY_OF` and
`NONE_OF` were all preserved, so this is a source-only break.

## Required migration

Rename the types. Nothing else has to change — no method names, no values.

```java
// before
PersonLabel label = new PersonLabel();
label.setSettableOn(Arrays.asList(EPersonLabelTargetType.AGENT));
List<PersonLabel> labels = person.getLabels();

// after
Label label = new Label();
label.setSettableOn(Arrays.asList(ELabelTargetType.AGENT));
List<Label> labels = person.getLabels();
```

For the licence feature map, wrap the value:

```java
// before
license.putFeaturesItem("example.feature", Boolean.TRUE);

// after
license.putFeaturesItem("example.feature", BooleanNode.TRUE);
```
