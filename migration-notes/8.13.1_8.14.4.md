# 8.13.1 → 8.14.4

`SuggestionSourceData` became an interface.

**This release breaks java code.** See [Required migration](#required-migration).

## What changed
`SuggestionSourceData` is now an interface, implemented by `CustomSuggestionSourceData`
and `CopilotSuggestionSourceData`. Its `TypeEnum` was removed, its methods became
abstract, and its `JSON_PROPERTY_*` constants disappeared.

This is what happens whenever a model gains its first variant: the schema becomes
polymorphic and the generated type changes from a class to an interface.

## Required migration

`new SuggestionSourceData()` no longer compiles. The pre-8.14.4 class corresponds to
`CustomSuggestionSourceData`.

```java
// before
SuggestionSourceData source = new SuggestionSourceData();

// after
CustomSuggestionSourceData source = new CustomSuggestionSourceData();
```

The declared type can stay `SuggestionSourceData` — it is now the interface — so only
the constructor has to change. Declaring the variant instead also gives access to the
members that only it has.
