# 8.26.2 → 8.27.2

A message translation property was renamed.

**This release breaks java code.** See [Required migration](#required-migration).

## What changed
`TextMessageTranslation.translatedText` was renamed to `text`. The old getter, setter and
fluent setter were removed.

## Required migration

Rename the accessors.

```java
// before
translation.setTranslatedText("Willkommen");
String value = translation.getTranslatedText();

// after
translation.setText("Willkommen");
String value = translation.getText();
```
