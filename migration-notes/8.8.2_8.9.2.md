# 8.8.2 → 8.9.2

An external messenger channel property was removed.

**This release breaks java code.** See [Required migration](#required-migration).

## What changed
`ExternalMessengerChannel.supportsMultipleConversationsPerContact` was removed, together
with its getter, setter and fluent setter.

The REST API still accepts and returns the property; only the java model dropped it.

## Required migration

Remove the calls. There is no replacement on the model.

```java
// before
channel.setSupportsMultipleConversationsPerContact(true);
boolean multi = channel.isSupportsMultipleConversationsPerContact();
```
